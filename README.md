# MicroBizFlow

**MicroBizFlow** é um app web simples que ajuda microempreendedores a gerar contratos automáticos e recibos digitais usando IA. Ideal para cabeleireiros, fotógrafos, técnicos, freelancers e outros pequenos prestadores de serviço.

---

## 🔹 Funcionalidades

- Cadastro de clientes
- Geração automática de contratos via IA
- Geração de recibos em PDF
- Integração futura com WhatsApp/email
- Painel simples e intuitivo

---

## 🔹 Tecnologias usadas

- **Backend:** Node.js + Express.js
- **Frontend:** HTML/CSS + JavaScript
- **IA:** OpenAI API (ChatGPT)
- **Autenticação e banco de dados:** Firebase
- **Hospedagem:** Vercel ou GitHub Pages
